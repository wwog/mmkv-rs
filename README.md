# mmkv-rs

A Rust port of [Tencent MMKV](https://github.com/Tencent/MMKV) **v2.4.3** with a
**byte-compatible on-disk format**. Stores written by C++ MMKV v2.4.3 are read
by this crate (including AES-CFB128 and key-expiration stores), and previously
verified Rust-written stores were read back by the C++ implementation.

The architecture follows GPUI's platform split: a single `Platform` contract,
with one crate per supported OS. Foundation access uses **`objc2`** — no Swift
shim, no Objective-C++ build step, no `cc` dependency.

## Crates

| Crate | Role |
|---|---|
| `mmkv` | Public façade: `init`, `open`, `default_store`, `Namespace`, static helpers |
| `mmkv-core` | Engine: format, MiniPB codec, CRC-32, meta, plaintext + AES-CFB128 store, registry, backup |
| `mmkv-platform` | Platform contract (`Platform`, `MappedRegion`, `AppLifecycle`) |
| `mmkv-platform-posix` | Shared POSIX mmap + `flock` + `ftruncate` primitives |
| `mmkv-platform-macos` | macOS integration via `objc2-foundation` |

## Implemented

- Append-only log, data-holder encoding, tombstones, full write-back, growth,
  `trim`, `clearAll(keepSpace)`.
- 112-byte `.crc` metadata, zlib CRC-32, sequence/actualSize/IV/flags.
- AES-CFB128 with AES-128/256 keys, random per-epoch IV, encrypted value holders
  (≤27 inline, ≤256 cached, >256 lazy offset holders), `rekey`.
- Key expiration (per-key timestamps, enable/disable migration, non-expired
  enumeration), compare-before-set, item size limit.
- Multi-process `flock` on `.crc`, content-change detection, incremental and
  full reloads, exclusive/try locks.
- Special-character ids (`specialCharacter/<md5>`), read-only instances,
  `Namespace`, backup/restore, import, `isFileValid`/`exist`/`removeStorage`.
- macOS default root `NSDocumentDirectory/mmkv`; App Group roots resolve to
  `<group>/mmkv`.

## Quick start (macOS)

```rust
fn main() -> mmkv::Result<()> {
    // Default root is NSDocumentDirectory/mmkv, like MMKV itself.
    mmkv::init(mmkv::InitOptions::default())?;

    let store = mmkv::default_store(&mmkv::StoreConfig::new())?;
    store.put_str("user", "alice")?;
    store.put_i64("counter", 42)?;
    store.sync();

    assert_eq!(store.get_str("user").as_deref(), Some("alice"));
    assert_eq!(store.get_i64("counter", 0), 42);
    Ok(())
}
```

Encrypted store:

```rust
let key = mmkv::CryptKey::new(b"0123456789abcdef".to_vec());
let store = mmkv::open(
    "com.example.secrets",
    &mmkv::StoreConfig::new().crypt_key(&key, false), // false = AES-128
)?;
store.put_str("token", "secret")?;
```

Explicit root:

```rust
let store = mmkv::open(
    "com.example.settings",
    &mmkv::StoreConfig::new()
        .root(std::path::Path::new("/tmp/mmkv"))
        .expected_capacity(64 * 1024),
)?;
```

## Tests

```bash
cargo test --workspace
```

62 tests cover:

| Suite | Coverage |
|---|---|
| `crates/mmkv/tests/fixtures.rs` | Reads stores produced by upstream C++ MMKV v2.4.3: plaintext, growth/trim/clear, special ids, AES-128/256, large values, single-key IV rotation, expiration |
| `crates/mmkv/tests/features.rs` | Crypt round-trips, appending to a C++ encrypted fixture, rekey, expiration migration, backup/restore, multi-process refresh, wrong-key safety |
| `crates/mmkv/tests/roundtrip.rs` | Plaintext append log, growth, trim, compare-before-set, value sizes |
| `crates/mmkv-core` unit tests | varint/MiniPB, CRC-32, meta layout, NIST AES-CFB128, CFB status reconstruction, holder thresholds |
| `crates/mmkv-platform-macos/tests/apple_platform.rs` | objc2 paths, page size, directory creation, App Group handling |

The binaries in `crates/mmkv/tests/fixtures/` were generated by the upstream
C++ core before the temporary test bridge was removed; see
`fixtures/README.md`.

## Compatibility notes

- On-disk bytes, file names, `.crc` metadata, CRC-32 semantics and path encoding
  match MMKV v2.4.3.
- iOS/macOS/watchOS/visionOS root: `NSDocumentDirectory/mmkv`; tvOS:
  `NSCachesDirectory/mmkv`.
- MMKV is BSD-3-Clause; this port keeps the license and attribution.
